# Privacy policy / Politica de privacidad

**App name:** rclone (personal OAuth client)
**Owner:** GitHub user peponConApel

## English

This OAuth client is created for personal use by its owner only. It lets the owner access his or her own Google Drive with the open source tool rclone, running on the owner's own computer.

- The app does not collect, store or transmit any user data to any server operated by the owner or any third party.
- Access tokens are stored only in a local configuration file on the owner's computer.
- No data is shared, sold or used for advertising.
- Access can be revoked at any time from the Google Account security settings (third-party apps with account access).

## Espanol

Este cliente OAuth se ha creado para uso personal de su propietario. Sirve para acceder al propio Google Drive con la herramienta de codigo abierto rclone, que se ejecuta en el ordenador del propietario.

- La aplicacion no recoge, almacena ni envia datos de usuario a ningun servidor del propietario ni de terceros.
- Los tokens de acceso se guardan solo en un fichero de configuracion local del ordenador del propietario.
- No se comparten ni se venden datos, ni se usan para publicidad.
- El acceso se puede revocar en cualquier momento desde la configuracion de seguridad de la cuenta de Google (aplicaciones de terceros con acceso a la cuenta).
